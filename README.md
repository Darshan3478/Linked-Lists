# Singly Linked List in C

This repository contains my implementations of **Singly Linked List (SLL)** operations in C as part of my Data Structures and Algorithms (DSA) practice.

## Topics Covered

- Creating a Singly Linked List
- Traversing the Linked List
- Insertion at the Beginning
- Insertion at the End
- Insertion at a Given Position
- Position Validation

## Node Structure

Each node contains:
- `data` - stores the value
- `next` - points to the next node

```c
struct node {
    int data;
    struct node *next;
};
```

C
